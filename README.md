# Pokey

Control a real iPhone from your Mac, and let AI agents drive it.

**[Download the latest version](https://github.com/Saransh29/pokey-releases/releases/latest/download/Pokey.dmg)** (macOS 14+)

Open the DMG, drag Pokey to Applications, and launch it. Setup walks you through the rest. Pokey updates itself: new versions show up in the app, or check any time from **Pokey › Check for Updates…**.

This repo only hosts release builds.
