# Zeptap

Control a real iPhone from your Mac, and let AI agents drive it.

**[Download the latest version](https://github.com/Saransh29/zeptap-releases/releases/latest/download/Zeptap.dmg)** (macOS 14+)

Open the DMG, drag Zeptap to Applications, and launch it. Setup walks you through the rest. Zeptap updates itself: new versions show up in the app, or check any time from **Zeptap › Check for Updates…**.

This repo only hosts release builds.
